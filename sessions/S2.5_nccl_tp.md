## 清单（只做这些）

1. **单卡对照**：`python 05_nccl_tp_probe.py --mode single`（一个 7B 量级的 matmul，拿到单卡 kernel 时间线基准）。
2. **TP=2 真实通信**：`--mode tp2`
   - 代码思路（注释里已写）：对一份分片权重做 TP 式 matmul + `dist.all_reduce`，循环多轮让通信在时间线上可辨。
3. **nsys 抓 TP2**：
   ```bash
   torchrun --nproc_per_node=2 ... nsys profile -o s25_tp2 python 05_nccl_tp_probe.py --mode tp2
   ```
4. **在时间线上回答三个问题**（回填到笔记）：
   - all-reduce 是一个 kernel 还是 ring 的多个 chunk kernel？（NCCL 版本相关，以所见为准）
   - 计算 kernel 与通信 kernel 是否有时间重叠？（没有重叠 = 通信纯串行成本）
   - 通信总量与消息大小的关系： TP 每层两次 all-reduce（forward+backward 训练场景；推理 forward 一次）——推理场景这里只看 forward。
5. （若时间富余）`NCCL_DEBUG=INFO` 重跑一轮，抓 ring/channel 建立日志，佐证时间线判断。
